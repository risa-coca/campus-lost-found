# 校园失物招领小程序（Campus Lost & Found）
> 毕业设计项目 | 微信小程序 + 后端管理系统

## ✨ 项目简介
本系统是面向校园的失物招领平台，分为**微信小程序端**和**后台管理端**。
学生可以发布失物、招领信息，查看物品详情、认领物品；管理员可以审核发布内容、管理用户与数据。

## 🛠 技术栈
- 前端小程序：微信原生小程序（WXML / WXSS / JS）
- 后台管理：Vue
- 后端：Node.js
- 数据库：MySQL

## 📖 功能模块
- 📝 发布失物信息 / 发布招领信息
- 🔍 分类检索、查看物品详情
- 🙋 在线留言认领
- 🧑‍💼 管理员：信息审核、信息管理、用户管理

## 🚀 运行说明
1. 后端：进入 backend，安装依赖，启动服务
2. 后台管理 admin：`npm install` → `npm run serve`
3. 小程序：使用微信开发者工具打开 miniprogram 文件夹
